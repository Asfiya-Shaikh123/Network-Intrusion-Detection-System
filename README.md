# 🛡️ Real-Time Network Intrusion Detection System (NIDS)

Advanced Machine Learning and Deep Learning dashboard for analyzing network targets and detecting suspicious traffic patterns.

## 🚀 Overview
This system uses trained Deep Learning (CNN-LSTM, CRNN, RNN, FFNN, NN) and Classical Machine Learning (Random Forest, SVM, Decision Tree, Logistic Regression, Gaussian Naive Bayes) models to evaluate traffic against:
- **NSL-KDD Dataset**
- **UNSW-NB15 Dataset**

## 💻 Tech Stack
- **Framework:** Python, Streamlit
- **Deep Learning:** TensorFlow / Keras
- **Machine Learning:** Scikit-Learn, Joblib
- **Data Processing:** Pandas, NumPy

## 🏃 Local Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
